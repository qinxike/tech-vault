量化研究的第一步，永远是**把数据拿到手里**。今天要介绍的通达信 tdxaidata（**tqs 模式**），是一个独立的 Python 数据包——**无需启动通达信客户端**，就能通过 API 自由获取 Tick 分笔、分时、竞价、分钟等各类数据。本文将带你完成环境搭建，并用实际代码演示 5 大核心数据场景。

## 一、环境搭建（3 步完成）

安装Python：建议使用Python3.7及以上版本

### 配置python
如果是在某个项目中(如tick-stock-panel)，使用tdx作为数据源。那么需要配置好python项目环境。

```
# 进入项目目录 
cd /Users/qinxike/works/workspace-ai/tick-stock-panel/backend 

# 创建虚拟环境
python3 -m venv .venv --with-pip 

# 激活环境(使用命令行的python指向虚拟环境的python)
source .venv/bin/activate 

# 给这个venv补pip(若pip没装)
.venv/bin/python -m ensurepip --upgrade --default-pip

```

### ① 安装 tdxaidata

```
# 安装 tdxaidata sdk
python -m pip install tdxaidata
# 使用清华镜像源安装，速度更快：
python -m pip install tdxaidata -i https://pypi.tuna.tsinghua.edu.cn/simple
已安装时直接升级：
python -m pip install -U tdxaidata -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 安装常用库

```
# 常用库安装：
pip install numpy pandas backtrader vectorbt ta-lib matplotlib
# 指定源安装：
- pip install numpy -i https://pypi.tuna.tsinghua.edu.cn/simple
- pip install pandas -i https://pypi.tuna.tsinghua.edu.cn/simple
- pip install backtrader -i https://pypi.tuna.tsinghua.edu.cn/simple
- pip install vectorbt -i https://pypi.tuna.tsinghua.edu.cn/simple
- pip install ta-lib -i https://pypi.tuna.tsinghua.edu.cn/simple
- pip install matplotlib -i https://pypi.tuna.tsinghua.edu.cn/simple
```
