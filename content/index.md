# Tech Vault(技术知识库)

通用技术知识库，记录技术方案与操作实践笔记。

## 主要内容

- **00-ai**：大模型应用、提示词、AI 工具链
- **01-bigdata**：数仓、计算引擎、数据平台组件
- **02-forecast**：预测建模、算法与指标方法
- **05-backend**：服务端技术方案与中间件
- **07-frontend**：页面、组件、前端工程化
- **09-ops**：服务器、部署、监控与故障处理
- **vault-docs**：本知识库编写和建站相关（obsidian / quartz / workflow）

## 说明

与 Dev Vault 的分工：**能落到具体代码/工程实践**的放 Dev Vault，**方案选型、设备、环境、工具使用**类的放本库。
