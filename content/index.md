# Tech Vault(技术知识库)

通用技术知识库，记录技术方案与操作实践笔记。

## 主要内容

- **00-ai**：AI相关，大模型应用、提示词、AI 工具链
- **01-bigdata**：大数据，数仓、计算引擎、数据平台组件
- **02-forecast**：数据预测，建模、算法与指标方法
- **03-quant**: 股票量化，量化相关
- **06-backend**：后端开发，服务端技术方案与中间件
- **07-frontend**：前端开发，页面、组件、前端工程化
- **09-ops**：运维部署，服务器、部署、监控与故障处理
- **vault-docs**：知识库相关，本知识库编写和建站相关（obsidian / quartz / workflow）
