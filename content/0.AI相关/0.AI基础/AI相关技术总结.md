# AI相关技术

## AI应用工具类型：

- 对话式AI：早期对话式的app，如：豆包，元宝，chatGpt

- 应用辅助AI：日常生活工作处理，文档资料数据整理，PPT，方案整理，问题排查解决。如: workBuddy，豆包工作。

- 辅助开发AI：AI插件内嵌在IDE中，或者封装为IDE，如：Tare，CodeBuddy，帮助我们开发项目工程，开发功能。开发者使用。

- AI技能插件开发：
  - Skills
  - MCP
  - Workbuddy插件
  - Deepseek harness插件

- AI开发框架：面向开发人员，开发AI应用时使用的框架。如: **LangChain**，**LangGraph**，**Deep Agents**(deepagents / deepagentsjs)
  **CrewAI**，多角色上手极快，声明式；写多角色协作几十行搞定；独立生态不依赖 LangChain。角色分工、快速原型。

- Agent AI：使用者提需求，Agent自动生成项目，实现功能并部署，一条龙全包，如：codex App，CodeBuddy(包含IDE + Agent)
  普通人也可以用来开发。

- 全代理AI：OpenClaw，高度自动化，从需求到开发到部署
