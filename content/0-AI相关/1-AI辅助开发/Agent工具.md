# AI Agent工具

## 开发类Agent

### Claude code(CLI)：账号封禁严

### Codex: (Agent，插件，CLI)

- App端下载：<https://openai.com/zh-Hans-CN/codex/>
- Codex CLI安装: `npm i -g @openai/codex`

### Codebuddy: (IDE，Agent，插件，CLI)

- App端下载: <https://www.codebuddy.cn/home/>
- CLI安装: `npm install -g @tencent-ai/codebuddy-code`

### Deepseek harness: (Agent)

- Github: <https://github.com/deepseek-ai/deepseek-harness>
- App端下载: <https://www.deepseek.com/harness/>
- CLI安装: `npm install -g @deepseek-ai/dsh`
  命令行启动:  `dsh web`
  npm安装，需要node22.23版本，或者使用node24版本。
